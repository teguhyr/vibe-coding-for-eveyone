# 📝 Evaluasi Level 1: Pre-test, Post-test & Umpan Balik

| | |
|---|---|
| **Kapan** | **Pre-test:** 10 menit pertama Sesi 1. **Post-test:** akhir Sesi 4 |
| **Durasi** | 10 menit |
| **Tujuan** | Mengukur peningkatan pemahaman peserta dan memperbaiki pelatihan berikutnya |

Pre-test dan post-test memakai **soal yang sama**. Peserta **tidak** diberi kunci jawaban setelah pre-test.

---

## Bagian A: Soal Pilihan Ganda (15 soal)

**1.** Dalam vibe coding, siapa yang bertanggung jawab atas kebenaran hasil program?
- a) AI yang menulis kode
- b) Tim IT
- c) Orang yang membuat dan memakai program
- d) Vendor perangkat lunak

**2.** Urutan siklus vibe coding yang benar adalah...
- a) Jalankan → Jelaskan → Periksa → AI membuat → Perbaiki
- b) Jelaskan → AI membuat → Jalankan → Periksa → Perbaiki
- c) AI membuat → Jalankan → Jelaskan → Perbaiki → Periksa
- d) Jelaskan → Jalankan → AI membuat → Perbaiki → Periksa

**3.** Fungsi folder `.venv` adalah...
- a) Menyimpan data rahasia
- b) Menyimpan Python dan library khusus untuk satu proyek
- c) Menyimpan riwayat Git
- d) Mempercepat internet

**4.** Perintah terminal untuk mengetahui folder tempat Anda berada sekarang adalah...
- a) `ls`
- b) `cd ..`
- c) `pwd`
- d) `clear`

**5.** Claude meminta izin menjalankan `rm -rf modules/03-hr/data`. Tindakan yang tepat adalah...
- a) Setujui, Claude pasti tahu yang terbaik
- b) Tolak, karena perintah ini menghapus folder data secara permanen
- c) Setujui lalu periksa nanti
- d) Pilih "jangan tanya lagi"

**6.** Huruf **C** kedua dalam R-C-T-C-O adalah...
- a) Context
- b) Code
- c) Constraints
- d) Check

**7.** Bagian prompt yang **wajib** berisi nama kolom dan contoh baris data fiktif adalah...
- a) Role
- b) Context
- c) Task
- d) Output

**8.** Bolehkah menempelkan 3 baris data gaji karyawan asli ke prompt sebagai contoh?
- a) Boleh, asalkan hanya 3 baris
- b) Boleh, jika atasan setuju lisan
- c) Tidak boleh; gunakan data fiktif dengan format yang sama
- d) Boleh, jika memakai Claude Code

**9.** Apa hasil kode berikut?
```python
target = 80
nilai = 80
if nilai >= target:
    print("TERCAPAI")
else:
    print("BELUM")
```
- a) `TERCAPAI`
- b) `BELUM`
- c) Error
- d) Tidak menampilkan apa pun

**10.** Pesan `IndentationError` biasanya berarti...
- a) Nama variabel salah ketik
- b) Baris di dalam `if`/`for`/`def` tidak menjorok
- c) File tidak ditemukan
- d) Internet terputus

**11.** Pemakaian 10 unit/hari, waktu antar 3 hari, stok pengaman 5. Reorder point-nya adalah...
- a) 18
- b) 30
- c) 35
- d) 50

**12.** Dalam aturan "Cek 3 Baris", baris yang **paling** penting ikut diperiksa adalah...
- a) Tiga baris pertama
- b) Baris dengan angka terbesar saja
- c) Baris normal, baris ekstrem, dan baris kasus tepi
- d) Tiga baris acak

**13.** Mengapa modul keuangan memakai `Decimal`, bukan `float`, untuk uang?
- a) `Decimal` lebih cepat
- b) `float` tidak bisa menyimpan beberapa pecahan secara persis, sehingga muncul selisih pembulatan
- c) `float` tidak bisa menyimpan angka negatif
- d) Tidak ada bedanya

**14.** Dalam tampilan *diff*, baris yang diawali tanda `+` berarti...
- a) Baris dihapus
- b) Baris ditambahkan
- c) Baris berisi error
- d) Baris tidak berubah

**15.** Perintah yang **selalu** dijalankan sebelum `git commit` untuk memastikan tidak ada file rahasia yang ikut tersimpan adalah...
- a) `git push`
- b) `git status`
- c) `git log`
- d) `git init`
